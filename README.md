## About Me

我是一名关注数字人文、档案与方志研究、以及人工智能应用的研究者。我的兴趣在于利用计算方法、知识组织与大模型技术，推动历史文献、地方文史资料与文化遗产材料的智能化整理、分析与呈现。

我希望把研究方法与技术实践结合起来，探索“AI × 人文研究”在知识发现、文本分析、信息组织和数字传播中的可能性。

## Research Interests

- 数字人文与计算方法
- 档案与地方文献的智能化研究
- 方志、文史资料、文化记忆的知识组织
- 大模型与智能体在学术研究中的应用
- 知识图谱、信息检索与结构化研究

## Current Focus

- 探索历史文献与档案材料的智能分析方法
- 构建面向文史研究的知识组织与检索框架
- 研究大模型在人文学术场景中的应用路径
- 结合信息技术推进地方文史数字化研究
